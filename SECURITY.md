# Security Policy

## Supported versions

Security reports are accepted for the current version on the `main` branch.
There are no separate versioned releases at this time.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's private
vulnerability reporting for this repository, or contact the maintainer
privately through the contact information on their GitHub profile.

Include the affected file or dependency, steps to reproduce, and potential
impact. Do not include private images, credentials, or other sensitive
information in a report.

The maintainer will acknowledge reports as soon as practical, investigate,
and coordinate any fix or disclosure with the reporter.
